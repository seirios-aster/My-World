# Chibi base model

The character body in `chibi-base.glb` is based on:

- **Title:** Free Pack - Chibi Base Mesh (Rigged)
- **Author:** DuNguyn Studio (https://sketchfab.com/dunguyn)
- **Source:** https://sketchfab.com/3d-models/free-pack-chibi-base-mesh-rigged-fed4fb329f224f1594f631eae8d2626b
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0) - http://creativecommons.org/licenses/by/4.0/

## Changes made

The file `chibi-base.glb` is the original, only renamed. In the game it is modified at runtime: it is recoloured (skin tones), given a painted face, hair, clothes and accessories built in code, and posed and animated through its skeleton.
